## 🌟 6 Killer Features That Distinguish GoDine

### 🤖 1. Autonomous AI Agent Engine (Floating Concierge)
> *Don't search. Just ask your AI Agent to execute actions for you.*

Floating across **every page of the platform**, our intelligent AI agent doesn't just answer questions — **it executes real actions on the website for you**:
- **`"Book a table at Copper Kettle Bistro"`** ➔ Instantly opens the Reservation Manager prefilled.
- **`"Create a post about my dinner"`** ➔ Activates the Post Creator modal with GPS tags.
- **`"Search hotels near me"`** ➔ Filters OpenStreetMap and switches your view to **Explore Map**.
- **`"Info on Aura Boutique Hotel"`** ➔ Navigates directly to the full venue profile.

### 📡 2. 1-Tap Nearby Deals & Offer Radar
> *Scan live discounts & promos within walking distance in 1 tap.*

- Tap the **"Deals Radar"** chip anywhere in the app to trigger an instant GPS scan of nearby venues.
- Detects active **20% OFF TODAY**, **15% OFF SPECIAL**, and flash promos from local merchants.
- Includes **1-tap instant table & room booking** right from the radar results!

### 💬 3. Direct User & Merchant Social Network
> *Connect directly with foodies, travelers, and venue managers.*

- Peer-to-peer messaging system allowing users to chat directly using **User IDs, handles (`@alex_rivera`), or email addresses**.
- **`+ New Chat`** modal lets you start direct messaging channels instantly.
- Seamlessly switch between user-to-user conversations and the **GoDine AI Assistant**.

### 📊 4. Aspect-Based AI Sentiment Analysis (ABSA)
> *Know exactly what is great before you walk through the door.*

Unlike primitive star ratings, GoDine's NLP pipeline breaks reviews into 3 key culinary & hospitality pillars:
- 🍲 **Taste Score** (e.g. `4.9 / 5.0`) — Evaluates specific dish flavors, freshness, and portion size.
- 🏛️ **Ambience Score** (e.g. `4.8 / 5.0`) — Measures decor, lighting, seating comfort, and noise levels.
- ⚡ **Service Score** (e.g. `4.7 / 5.0`) — Evaluates staff hospitality, speed, and reservation fulfillment.

### 🗺️ 6. OpenStreetMap & Geoapify Hyper-Local Engine
> *Real GPS precision from 200 meters to 15 kilometers.*

- Interactive Leaflet map powered by **OpenStreetMap Overpass QL** querying real-world locations.
- Categorized custom pins for **Hotels 🏨, Motels 🚗, Resthouses 🏡, Restaurants 🍽️, Cafes ☕, and Bakeries 🥐**.
- Geoapify integration automatically resolves physical text addresses into accurate map pin coordinates.

### 🔐 6. Enterprise-Grade Security & Authentication
> *Sleek login flow with Google OAuth 2.0 & Encrypted Bearer JWT.*

- **Google OAuth 2.0**: One-click Google Identity Sign-In verified server-side with fallback tokeninfo verification.
- **Encrypted JWT Bearer Security**: 7-day persistent session tokens attached automatically to API request headers.

## ⚡ Quick Start

### 1. Launch Backend API Gateway
```bash
cd backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt

# Run FastAPI server with hot reload
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
- Swagger Interactive Docs: `http://localhost:8000/docs`

### 2. Launch Frontend Web App
```bash
cd frontend
npm install
npm run dev
```
- Web Application: `http://localhost:5173`
